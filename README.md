# Lane Bluff Duel (spike)

Ship Lab week-1 browser spike — hotseat + dumb AI.

## Play
1. Vs dumb AI or Hotseat
2. Pick card → tap lane → Face-up or Face-down
3. Place 3 cards each → win 2 of 3 lanes → Rematch

Rules on screen: Commit a card to a lane. Face-up = effect now. Face-down = bluff until reveal. Win 2 of 3 lanes.
